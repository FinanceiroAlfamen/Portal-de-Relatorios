## Estrutura

O arquivo index.html contém os estilos, fontes e imagens incorporados. Pode ser aberto diretamente ou publicado no GitHub Pages, sem instalação de dependências. Os relatórios abrem em novas abas.

Tema claro/escuro com preferência salva no navegador, layout responsivo e respeito à preferência de movimento reduzido.

Para atualizar, substitua index.html na branch main. A publicação usa a raiz da branch main. links-relatorios.json registra os destinos; alterações de destino também precisam ser aplicadas aos links do HTML.
